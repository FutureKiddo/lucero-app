Cómo se instala

No está en Play Store: se descarga desde aquí. Es normal que el móvil pregunte.

smartphoneAndroid

  1. Toca Descargar para Android y espera a que acabe.
  2. Ábrelo desde la notificación o desde Mis archivos › Descargas.
  3. Si te pide permiso para instalar apps de tu navegador, dale a Permitir.
  4. Toca Instalar. Para actualizar, lo mismo: se instala encima.

desktop_windowsWindows

  1. Toca Descargar para Windows.
  2. Abre el instalador. Si sale «Windows protegió tu PC», toca Más información › Ejecutar de todas formas.
  3. Listo: Lucero aparece en el menú Inicio.

phone_iphoneiPhone y Mac

De momento no hay una forma fácil de instalarla: Apple pide pagar cada año para publicar apps. En cuanto se pueda, lo contaremos.
